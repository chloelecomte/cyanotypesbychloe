## Negative Studio

`negative-studio/index.html` is a standalone, single-file web app for turning digital photos into corrected negatives for cyanotype printing (B&W conversion, adjustable negative curve, cyanotype preview, step-tablet calibration, print-ready PNG export). It runs entirely in the browser with no dependencies; open the file directly or visit `/negative-studio/` on the site.
